# 案例：HW4 核影像、視差圖與點雲

## 背景與輸入
課堂要求用具有視差的教室或空拍照片，求 E／R／T、建立核影像、使用 SGBM 估視差，再交會成三維點雲。需相機模型、有效對應，以及若要公尺單位則必須有尺度來源。[S07 pp.48,54]

## 方法與操作流程
檢查取像與內參 → 去畸變與特徵匹配 → 幾何估計 F／E → SVD 候選／前方深度選解 → 核影像糾正 → 檢查 y 視差 → SGBM → 視差單位與有效遮罩 → 三角交會／點雲 → 分析遮蔽與誤差。[S07 pp.17–39,48,51–54；流程補齊]

## 應保存的結果
| 產物 | 檢查 |
| --- | --- |
| F／E／R／T | 對應來源、rank、旋轉正交性與 det、平移尺度 |
| 核影像 | 同名點的垂直殘差、裁切與新內參 |
| 視差圖 | 搜尋範圍、儲存倍率、無效區及左右一致性 |
| 點雲 | 單位、座標系、負深度／離群值與真值比較 |

## 限制與缺漏
未取得實際照片、相機率定與基線，故不報新實驗點雲或精度。教材提及 ToF／Kinect 是另一種感測路線，硬體世代未指定時不把所有 Kinect 都視為同一測距原理。[S07 pp.46–49,54；補充界線]

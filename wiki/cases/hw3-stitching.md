# 案例：HW3 拼接與模型比較

## 背景與輸入
用工業相機拍兩張錯位影像，修正畸變、找特徵對應，分別以 Affine 與 Perspective 模型拼接，畫誤差向量並比較誤差。[S03 p.25]

## 方法與操作流程
固定並記錄相機模型 → 修正鏡頭畸變 → 偵測／描述／匹配 → 幾何過濾 → 用同一批有效點估計兩模型 → 定義輸出畫布 → 反算及內插 → 比較重疊區與誤差向量。[S03 pp.18–25,31–54；流程補齊]

## 應比較的結果
| 欄位 | 記錄內容 |
| --- | --- |
| 有效對應 | 數量、分布、幾何模型與過濾門檻 |
| 殘差 | 每點二維 RMSE 或自由度校正尺度，寫出分母 |
| 系統偏差 | 中心／四周向量是否呈規律 |
| 視覺結果 | 接縫、重影、孔洞、裁切及內插方式 |

**補充判讀**：對相同資料，參數較多的模型可能有較低擬合誤差；仍須保留檢核點或觀察未參與估計的區域，不能直接宣稱透視一定比較好。[S03 pp.24–25,34；補充驗收]
